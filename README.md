Prompts และ GPT ที่ใช้ในการทำงาน

ในการพัฒนาโครงงาน ผู้จัดทำเป็นผู้วางแผน วิเคราะห์ข้อมูล ออกแบบ Dashboard และลงมือพัฒนาระบบด้วยตนเอง โดยใช้ GPT เป็นเครื่องมือช่วยให้คำปรึกษาในบางขั้นตอน เช่น การตรวจสอบแนวคิด การอธิบาย Error การแนะนำแนวทางการเขียนโค้ด และการปรับปรุงรูปแบบการนำเสนอ

ผู้จัดทำไม่ได้ใช้ GPT ในการทำงานทั้งหมดแทน แต่จะนำคำแนะนำที่ได้รับมาพิจารณา ปรับแก้ให้เหมาะสมกับโครงงาน และทดสอบการทำงานด้วยตนเองก่อนนำมาใช้งานจริง

ตัวอย่าง Prompt ที่ใช้
Prompt 1 — ตรวจสอบแนวทางการทำความสะอาดข้อมูล
Prompt:
“ฉันกำลังตรวจสอบ Dataset สำหรับนำไปทำ Dashboard ช่วยแนะนำว่าควรตรวจสอบคุณภาพข้อมูลในด้านใดบ้าง เช่น Missing Values, Duplicate และ Outlier พร้อมอธิบายเหตุผลของแต่ละขั้นตอน”

GPT ช่วย:
ให้แนวทางและรายการตรวจสอบคุณภาพข้อมูล เพื่อใช้เป็นแนวทางประกอบการวิเคราะห์ โดยผู้จัดทำเป็นผู้ตรวจสอบข้อมูลจริงและตัดสินใจว่าจะจัดการข้อมูลอย่างไร

Prompt 2 — ขอคำแนะนำในการเลือกกราฟ
Prompt:
“ฉันต้องการวิเคราะห์ข้อมูลการฝากเงินของลูกค้า โดยมีตัวแปร Job, Deposit, Age และ Balance ช่วยแนะนำว่าควรใช้กราฟประเภทใดกับข้อมูลแต่ละส่วน และแต่ละกราฟเหมาะสำหรับตอบคำถามอะไร”

GPT ช่วย:
เสนอทางเลือกของ Visualization และอธิบายข้อดีของกราฟแต่ละประเภท จากนั้นผู้จัดทำเป็นผู้เลือกกราฟที่เหมาะสมกับ Dashboard

Prompt 3 — ตรวจสอบโครงสร้าง Dashboard
Prompt:
“ฉันออกแบบ Dashboard สำหรับวิเคราะห์ข้อมูลการฝากเงิน โดยต้องการมี KPI, กราฟ และตารางข้อมูล ช่วยตรวจสอบว่าโครงสร้างที่ออกแบบมีส่วนใดที่ควรเพิ่ม ลด หรือปรับตำแหน่งเพื่อให้ผู้ใช้งานเข้าใจข้อมูลได้ง่ายขึ้น”

GPT ช่วย:
ให้คำแนะนำด้านการจัด Layout และลำดับการนำเสนอข้อมูล โดยผู้จัดทำเป็นผู้ตัดสินใจและนำไปปรับใช้เอง

Prompt 4 — ขอคำแนะนำเกี่ยวกับการเขียน Vue.js
Prompt:
“ฉันกำลังพัฒนา Dashboard ด้วย Vue.js และต้องการแยกส่วน Filter, KPI, Chart และ Table ช่วยอธิบายว่าควรจัดการ State และ Event ของแต่ละส่วนอย่างไร”

GPT ช่วย:
อธิบายแนวคิดเกี่ยวกับ State และ Event พร้อมเสนอแนวทางการจัดโครงสร้างโค้ด เพื่อให้ผู้จัดทำสามารถนำไปปรับกับโค้ดของตนเอง

Prompt 5 — วิเคราะห์ Error ที่เกิดขึ้นจริง
Prompt:
“จาก Console พบ Error Papa is not defined ในโปรเจกต์ Vue.js ฉันต้องการทราบว่าสาเหตุเกิดจากอะไร และมีวิธีตรวจสอบหรือแก้ไขอย่างไรบ้าง โดยต้องการทำความเข้าใจปัญหาก่อนแก้ไข”

GPT ช่วย:
อธิบายสาเหตุของ Error และเสนอทางเลือกในการแก้ไข จากนั้นผู้จัดทำตรวจสอบโครงสร้างไฟล์ของตนเองและเลือกวิธีที่เหมาะสม คือการใช้ fetch() และ Custom CSV Parser

Prompt 6 — ขอคำแนะนำเรื่อง Interactive Chart
Prompt:
“ฉันต้องการให้กราฟใน Dashboard สามารถกดแล้วเกิด Interaction เช่น Filter ข้อมูล หรือ Replay Animation ช่วยอธิบายแนวทางการทำ Event ของ Chart.js และสิ่งที่ควรระวัง”

GPT ช่วย:
อธิบายหลักการทำ Event ของ Chart.js และแนวทางการเชื่อมกับ Vue.js จากนั้นผู้จัดทำเป็นผู้เลือก Interaction ที่เหมาะสมและนำไปทดลองใช้งาน

Prompt 7 — ตรวจสอบปัญหาปุ่ม Reset
Prompt:
“ฉันสร้าง Filter สำหรับ Job และ Deposit Status แล้ว แต่เมื่อกด Reset ต้องการให้ค่าทั้งหมดกลับไปเป็นค่าเริ่มต้นและให้กราฟกับตารางอัปเดตตาม ช่วยตรวจสอบแนวคิดการทำงานและแนะนำจุดที่ควรตรวจสอบ”

GPT ช่วย:
ช่วยวิเคราะห์ความสัมพันธ์ระหว่าง Filter, State และการ Update Chart โดยผู้จัดทำเป็นผู้ตรวจสอบโค้ดและแก้ไขตามคำแนะนำ

Prompt 8 — ขอคำแนะนำด้าน UI/UX
Prompt:
“ฉันออกแบบ Dashboard สำหรับนำเสนอในชั้นเรียน ต้องการให้ดูเรียบง่าย อ่านง่าย และมีความแตกต่างจาก Dashboard D3.js ช่วยเสนอแนวทางด้านสี Layout, Card, Spacing และการจัดวางกราฟ โดยยังคงเน้นการอ่านข้อมูลเป็นหลัก”

GPT ช่วย:
เสนอแนวทางด้าน UI/UX เช่น การใช้สี Pastel การจัด Card และ Grid Layout จากนั้นผู้จัดทำเลือกแนวทางที่เหมาะสมและนำมาปรับใน style.css ด้วยตนเอง

บทบาทของ GPT ในโครงงาน
GPT ถูกใช้ในลักษณะ ผู้ช่วยให้คำปรึกษา (AI Assistant) มากกว่าการให้ทำงานแทนทั้งหมด โดยผู้จัดทำเป็นผู้กำหนดโจทย์ วิเคราะห์ข้อมูล ออกแบบ Dashboard เลือกวิธีการนำเสนอ และทดสอบผลลัพธ์ด้วยตนเอง

กระบวนการทำงานโดยสรุปคือ

ผู้จัดทำคิดและวางแผน → ลงมือพัฒนา → พบปัญหา → ขอคำแนะนำจาก GPT → นำคำแนะนำมาวิเคราะห์ → ปรับแก้ด้วยตนเอง → ทดสอบผลลัพธ์ → เลือกแนวทางที่เหมาะสม

ดังนั้น GPT เป็นเพียงเครื่องมือสนับสนุนการเรียนรู้และแก้ไขปัญหา ในขณะที่การตัดสินใจและการดำเนินงานหลักของโครงงานยังอยู่ที่ผู้จัดทำ
